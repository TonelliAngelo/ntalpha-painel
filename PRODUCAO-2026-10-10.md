# NT ALPHA — Entrada em produção

## Ordem obrigatória

1. Faça um backup do projeto e mantenha o `NT_ALPHA_BACKUP_FULL_2026-10-10.zip` intacto.
2. No Supabase **Production**, abra SQL Editor.
3. Rode primeiro somente esta consulta de pré-validação:

```sql
select property_id, count(*) as capas
from public.property_images
where tipo = 'foto' and principal = true
group by property_id
having count(*) > 1;
```

O resultado esperado é **0 linhas**.

4. Rode `supabase/2026-10-10-production-hardening.sql`.
5. Faça o deploy dos arquivos deste pacote.
6. No painel, entre com um usuário autorizado.
7. Teste cadastro de um imóvel real em modo `publicar_site = false`.
8. Confirme no Supabase que o imóvel, proprietário e mídias foram gravados.
9. Teste remover uma foto de teste e confirme que ela desapareceu do Storage e de `property_images`.
10. Teste o XML OLX.
11. Teste o XML ZAP.
12. Teste o XML VivaReal.
13. Só depois habilite os canais para imóveis reais.

## Variáveis do Worker

Obrigatórias no ambiente de produção:

- `NEXT_PUBLIC_SUPABASE_URL`
- `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY`
- `SUPABASE_SECRET_KEY`

`SUPABASE_SERVICE_ROLE_KEY` continua aceito somente como legado.

**Nunca** coloque `SUPABASE_SECRET_KEY` ou `SUPABASE_SERVICE_ROLE_KEY` em variável `NEXT_PUBLIC_*`.

## URLs de validação

- `/api/integracao/health`
- `/api/integracao/olx`
- `/api/integracao/vrsync?channel=zap`
- `/api/integracao/vrsync?channel=vivareal`

## Critério para liberar produção

Um imóvel só deve ser habilitado para OLX/ZAP/VivaReal depois de:

- status `disponivel`;
- código existente;
- título adequado;
- cidade/UF/CEP/bairro preenchidos;
- valor de venda preenchido;
- descrição adequada;
- mínimo de 5 fotos JPG/JPEG para os feeds atuais;
- uma foto principal;
- endereço tratado conforme a opção de exibição.

## Exclusão

A exclusão de mídia e imóvel passou a usar endpoints administrativos do servidor. O navegador envia apenas o token da sessão; a chave secreta fica no Worker.

Se a exclusão do imóvel retornar erro de FK/histórico, **não apague tabelas manualmente**. Use `status = inativo` até avaliarmos a regra de retenção do histórico.
